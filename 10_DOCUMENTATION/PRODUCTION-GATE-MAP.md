# Production Gate Map

## Gate A: Concept
Input: idea
Output: approved Story Spec

## Gate B: Canon
Input: Story Spec
Output: approved Show Bible

## Gate C: Character
Input: Character Spec + reference package
Output: approved identity

## Gate D: Scene
Input: script + canon
Output: approved Scene Specs

## Gate E: Shot
Input: Scene Specs
Output: approved Shot Specs

## Gate F: Image
Input: Shot Specs + references
Output: approved keyframes

## Gate G: Video
Input: approved keyframes
Output: approved video shots

## Gate H: Audio
Input: script + performance
Output: approved dialogue/audio

## Gate I: Edit
Input: approved video + audio
Output: master candidate

## Gate J: Final QA
Input: master candidate + provenance
Output: READY or BLOCKED

## Gate K: Publish
Input: READY
Output: published version + archive

## Global blockers

Any of these stops the pipeline:

- unauthorized cost
- unknown licensing
- character identity drift
- voice identity drift
- unresolved continuity contradiction
- severe visual artifact
- corrupted media
- missing provenance
- failed technical master
