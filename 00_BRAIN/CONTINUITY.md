# Continuity System

Continuity is a hard production constraint, not an optional polish pass.

## Track
- Character appearance
- Wardrobe
- Hair and accessories
- Character relationships
- Location geography
- Time and chronology
- Props
- Injuries and physical state
- Emotional state when relevant to scene logic
- Dialogue facts
- Previous episode events
- Visual style

## Severity
- BLOCKER: contradiction that breaks canon or scene logic
- MAJOR: inconsistency likely visible to viewers
- MINOR: small inconsistency that does not alter story meaning

## Resolution
1. Detect contradiction.
2. Identify the canonical source.
3. Propose a correction.
4. Update the affected production record only after approval.
5. Re-run downstream QA.
