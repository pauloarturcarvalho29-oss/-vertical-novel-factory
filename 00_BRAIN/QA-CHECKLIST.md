# Brain QA Checklist

## Narrative
- [ ] Episode objective is clear
- [ ] Hook appears early
- [ ] Character actions match motivations
- [ ] Dialogue is coherent
- [ ] Ending creates the intended continuation

## Continuity
- [ ] Character identity is consistent
- [ ] Wardrobe is consistent
- [ ] Location/time are consistent
- [ ] Props and physical state are consistent
- [ ] No canon contradictions

## Production
- [ ] Every scene has a purpose
- [ ] Every shot has a duration
- [ ] Required references exist
- [ ] Prompts derive from structured specs
- [ ] 9:16 composition is respected

## Rights
- [ ] External assets are recorded
- [ ] Model/tool licenses are recorded
- [ ] No unknown copyrighted asset is silently incorporated
