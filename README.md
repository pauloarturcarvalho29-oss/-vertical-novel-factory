# Vertical Novel Factory

AI-powered open-source production system for original vertical novels.

## Vision
Build an end-to-end, mobile-first production pipeline for original short-form fictional series for TikTok and YouTube, with reproducible workflows and transparent licensing.

## Architecture
**iPhone** → control, review and publishing

**ChatGPT** → story brain, planning, continuity, prompts and QA

**Compute** → image/video/voice generation and rendering

**GitHub** → source of truth for workflows, documentation and production manifests

## Pipeline
Story → Characters → Storyboard → Images → Video → Voice → Audio → Subtitles → Edit → Publish → Analytics

## Principles
- Original characters and stories
- Mobile-first operation
- 1080×1920 / 9:16 master format
- Short shots assembled into episodes
- Free/open-source first
- Explicit approval for paid or uncertain-cost services
- License provenance for every external dependency
- Reproducible workflows
- Quality gates at every stage
