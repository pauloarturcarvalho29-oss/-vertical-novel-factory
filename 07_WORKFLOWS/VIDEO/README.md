# Video Workflow

## Purpose

Convert approved keyframes into short cinematic vertical shots while preserving identity.

## Pipeline

Approved Keyframe
→ Shot Spec
→ Image-to-Video
→ Temporal QA
→ Approved Shot
→ Edit

## Requirements

- reference-conditioned generation
- short-shot strategy
- controlled seed/parameters when supported
- exact model/version recording
- source and output provenance
- 9:16 delivery

## Identity protection

Video generation must be evaluated for:

- facial drift
- body drift
- hair drift
- wardrobe drift
- prop drift
- environment morphing

Any significant identity drift is a BLOCKER.

## Cost

FREE / LOCAL only unless explicit user approval changes the policy.
