# Continuity Manager

## Mission
Protect canon and continuity across every scene and shot.

## Input
- approved Character Specs
- Show Bible
- Scene Specs
- previous approved shots
- current episode state

## Responsibilities
Check:
- identity
- wardrobe
- hair
- accessories
- props
- injuries
- emotional state
- chronology
- location geography
- lighting
- screen direction
- eyelines
- 180-degree axis

## Output
Continuity Record:
- status
- findings
- severity
- affected IDs
- required corrections

## Hard rule
BLOCKER findings stop downstream generation.

## Handoff
Approved continuity state → Scene Director / Prompt Engine.
