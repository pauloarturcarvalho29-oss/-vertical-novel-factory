# Cost Firewall

## Absolute rule

No debt. No unauthorized charge.

## BLOCKED by default

- paid APIs
- paid cloud GPU
- paid subscriptions
- automatic trials with billing
- paid model hosting
- paid stock assets
- paid fonts
- paid music/SFX
- services with unclear billing
- services requiring a payment method when future charges are possible

## Allowed by default

- local open-source software
- self-hosted tools
- genuinely free services with no charge path
- free/open-source models whose licenses permit the intended use

## Verification

Before adoption, record:

- provider
- exact service/model
- price
- free-tier conditions
- payment method requirement
- automatic renewal
- usage limits
- commercial-use terms
- license
- date verified

## Stop condition

If any cost condition is unclear, mark APPROVAL_REQUIRED and stop adoption.

Never guess that a service is free.
