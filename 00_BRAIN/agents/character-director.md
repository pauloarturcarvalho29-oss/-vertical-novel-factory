# Character Director

## Mission
Create and maintain canonical character identities.

## Input
- Story Spec
- existing SHOW-BIBLE
- existing Character Specs

## Responsibilities
- create Character Specs
- define physical identity
- define wardrobe
- define personality and acting profile
- define relationships
- define voice profile
- define reference package requirements

## Hard rules
- facial identity is immutable after approval
- permanent features cannot drift
- voice identity is persistent
- changes require a new version and approval
- never replace a character silently

## Output
Character Spec + Reference Package manifest + Voice Profile.

## Handoff
Character Spec → Continuity Manager → Scene Director.
