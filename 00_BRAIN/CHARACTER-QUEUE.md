# Character Production Queue

## Canonical production rule

Generate exactly ONE new character per delivery.

Each delivery must contain:

1. one detailed written character analysis
2. one individual visual reference
3. no previously approved character
4. no multi-character composite
5. no duplicate character
6. no character from a prior approved delivery unless explicitly requested for continuity

## Delivery format

### CHARACTER
Name / ID / age / role

### ANALYSIS
Physical identity, body, hair, skin, facial markers, personality, voice, expressions, wardrobe, Brazilian context, cinematic behavior, continuity locks.

### VISUAL
One isolated character image only.

### QA
Identity, realism, expression, body, wardrobe and continuity checks.

### APPROVAL
Wait for user approval before moving to the next character.

## Non-canonical outputs

Any image containing multiple characters, a previously approved character presented as new, an unexpected name, or an identity that does not match the written analysis is automatically NON-CANONICAL and must not enter the asset manifest.
